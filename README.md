# CBN.Ai

The public website for CBN.Ai, a research and development lab based in Dehradun. The homepage introduces Buji and links each project in the lab's public GitHub archive.

[Visit the site](https://devchandrasen.github.io/CBN.ai/)

The site is served from the root of the main branch on GitHub Pages. To preview it locally, run `python -m http.server 4181` from the repository directory and open `http://127.0.0.1:4181/`.

The project archive lives in `index.html`. Keep each entry's research area, description, and repository link together. Buji installer files and checksums are published separately on the [Buji releases page](https://github.com/Devchandrasen/buji/releases).
